# {{project-name}}

Device firmware for **{{board}}** (esp32-{{chip}}), generated by bonsai.

Built as a **trunk + branches**: `src/main.rs` (the trunk) brings up the
hardware, starts the built-in *pulse* (its cycle of life), then your branches.
Each subsystem lives under `src/branches/` and runs as an Embassy async task.

```
src/
├── main.rs            # trunk: HW init, starts the pulse, then branches
├── trunk.rs           # the Nutrient vocabulary + the Trunk handle
├── sap.rs             # GENERATED by bonsai: one channel per nutrient
├── pulse.rs           # built-in cycle of life (heartbeat + monitor)
└── branches/
    └── mod.rs         # registry — empty; your subsystems go here
```

## Grow the device

```sh
bonsai branch imu        # scaffolds src/branches/imu.rs and wires it in
bonsai branch telemetry
```

## Prerequisites

```sh
cargo install espup && espup install   # installs the Xtensa `esp` toolchain + linker
cargo install espflash                 # flashing + serial monitor
echo '. ~/export-esp.sh' >> ~/.bashrc  # or ~/.zshrc; then open a new terminal
```

In fish, the last line is instead:

```fish
echo 'source ~/export-esp.sh' >> ~/.config/fish/config.fish
```

espup puts the Xtensa linker (`xtensa-esp32s3-elf-gcc`) outside your `PATH`
and writes `~/export-esp.sh` to add it. Load that script in every terminal you
build from (the `echo` line does it for new ones; run `. ~/export-esp.sh`, or
`source ~/export-esp.sh` in fish, in the current one). Without it, the build
compiles and then fails with ``linker `xtensa-esp32s3-elf-gcc` not found``.

## Build & run

```sh
cargo build --release
cargo run --release            # flashes via `espflash flash --monitor`
```

{% if wifi %}## WiFi

`src/wifi.rs` joins a network at startup and keeps rejoining if it drops.
It also runs the network stack (DHCP, UDP, TCP, DNS). Name the network in
`.cargo/config.toml`:

```toml
WIFI_SSID = "my-network"
WIFI_PASSWORD = "my-password"   # empty for an open network
```

To keep the password out of git, delete that line and set it in your shell
instead. A variable from the shell wins over the file:

```sh
export WIFI_PASSWORD='my-password'
```

The log then shows the network and the address DHCP gave the board.

`wifi::start` returns `net`, the network stack. Hand it to a branch the same
way as a pin. A branch that sends a UDP datagram to a computer on every beat:

```sh
bonsai branch uplink
bonsai tap uplink Beat
```

In `src/main.rs`, pass `net` to it, and delete the `let _ = net;` placeholder:

```rust
    branches::uplink::start(&spawner, &trunk, net);
```

In `src/branches/uplink.rs`:

```rust
use embassy_net::udp::{PacketMetadata, UdpSocket};
use embassy_net::{Ipv4Address, Stack};

/// The computer the beats go to, and its port.
const PEER: (Ipv4Address, u16) = (Ipv4Address::new(192, 168, 1, 10), 9000);

pub fn start(spawner: &Spawner, _trunk: &Trunk, net: Stack<'static>) {
    spawner.spawn(
        run(sap::uplink::Taps::new(), net)
            .unwrap_or_else(|_| panic!("uplink: run already running")),
    );
}

#[embassy_executor::task]
async fn run(mut taps: sap::uplink::Taps, net: Stack<'static>) {
    // A socket needs buffers for the packets it holds; these live in the task.
    let (mut rx_meta, mut rx) = ([PacketMetadata::EMPTY; 4], [0u8; 256]);
    let (mut tx_meta, mut tx) = ([PacketMetadata::EMPTY; 4], [0u8; 256]);
    let mut socket = UdpSocket::new(net, &mut rx_meta, &mut rx, &mut tx_meta, &mut tx);
    socket
        .bind(9000)
        .unwrap_or_else(|_| panic!("uplink: can't bind port 9000"));
    loop {
        let nutrient: Nutrient = taps.next().await;
        #[allow(clippy::single_match, clippy::match_single_binding)] // until it taps more nutrients
        match nutrient {
            // tap nutrients with `bonsai tap uplink <Nutrient>`
            Nutrient::Beat => {
                let _ = socket.send_to(b"beat", PEER).await; // dropped while offline
            }
            // bonsai:nutrient-arm
            #[allow(unreachable_patterns)]
            _ => {}
        }
    }
}
```

On the computer, `nc -u -l 9000` prints `beat` twice a second.
